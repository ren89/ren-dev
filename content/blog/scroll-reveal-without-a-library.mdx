Animation libraries are great, but they're not free - they add JavaScript to every
page. For simple "fade in as it scrolls into view" effects, the platform already gives
you everything you need: **IntersectionObserver** and a CSS transition.

## The component

Here's the entire thing. It reveals its children once, and - importantly - shows them
immediately for anyone who prefers reduced motion.

```tsx title="components/reveal.tsx"
"use client";

import { useEffect, useRef, useState, type ReactNode } from "react";

export function Reveal({ children }: { children: ReactNode }) {
  const ref = useRef<HTMLDivElement | null>(null);
  const [shown, setShown] = useState(false);

  useEffect(() => {
    const el = ref.current;
    if (!el) return;

    // Respect the user's motion preference.
    const reduced = window.matchMedia(
      "(prefers-reduced-motion: reduce)",
    ).matches;
    if (reduced) {
      setShown(true);
      return;
    }

    const io = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setShown(true);
          io.disconnect();
        }
      },
      { threshold: 0.15 },
    );

    io.observe(el);
    return () => io.disconnect();
  }, []);

  return (
    <div
      ref={ref}
      className={`transition-all duration-700 ${
        shown ? "translate-y-0 opacity-100" : "translate-y-6 opacity-0"
      }`}
    >
      {children}
    </div>
  );
}
```

## Why I like it

- **Zero dependencies.** No extra JS shipped to the client.
- **Accessible by default.** Reduced-motion users get content instantly, no animation.
- **Composable.** Wrap anything, stagger with a `delay` prop if you want.

That's the whole trick. Reach for a library when you need orchestration or gestures -
but for a tasteful reveal, the browser has your back.
